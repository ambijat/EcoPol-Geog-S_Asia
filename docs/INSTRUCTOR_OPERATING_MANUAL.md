# Instructor Operating Manual

## The three learning layers

The course is built from three different kinds of evidence:

1. Historical classroom presentations show what was taught, in what sequence, and with which visual approach.
2. Raw scholarly and empirical resources provide the books, articles, reports, maps, datasets, and statistics needed to support or update the teaching.
3. Wikidot student-facing notes and links provide the explanatory and learning layer students encounter outside the classroom deck.

The website layer is not assumed to be verified merely because it is public. A note can be current, historical, AI-assisted, instructor-revised, unverified, superseded, or of unknown origin. The application records only what available evidence establishes.

## Production chain

```text
Historical PPT
+ Raw repository
+ Website learning layer
→ Triangulation
→ Revised note
→ Slide plan
→ Classroom deck
→ Student learning package
```

## Fixed items

High-fidelity inherited lecture titles remain in force unless evidence conflicts, a title is missing, the sequence is mismatched, or the instructor explicitly changes it.

The weekly allocation is fixed:

- Part A: Tuesday, 9:00–11:00
- Part B: Friday, 9:00–11:00

Routine title and A/B scheduling confirmations therefore do not belong in the active decision queue.

## Where instructor control begins

The first substantive control point is resource selection, source alignment, verification, and integration. Open **Lecture Triangulation**, choose a topic, and compare the three evidence columns.

Findings are advisory. A recommendation becomes an instructor decision only after an explicit decision and confirmation are recorded. Preparing a registry candidate does not add anything to the canonical registry.

## Student learning packages

A working package can connect a classroom deck, verified explanatory note, selected raw resources, public website links, and teaching brief. Creation is not publication. Verification and public approval remain separate instructor-controlled acts.

## Safe website intake

Use previously authorised metadata, a page address explicitly supplied by the instructor, an existing link inventory, or an individually authorised page inspection. Do not crawl the site or automatically download Wikidot attachments or Google Drive files.
