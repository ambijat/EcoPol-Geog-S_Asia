# Lecture Production Workspace

This is the central Semester 2026 classroom-production area. Each numbered lecture is ordinarily one week with Tuesday Part A and Friday Part B. Files here are drafts unless explicitly instructor-approved at F4. Historical originals remain outside this workspace and are never renamed or modified.

Each lecture folder contains a blank weekly blueprint and two part workspaces. Empty output directories use `.gitkeep` solely so Git can preserve the scaffold.
