# Owner Artefact Map

## How the course is built

The course uses three learning layers:

1. **Historical classroom presentations** — inherited teaching sequence, claims, maps, examples, and visual pedagogy.
2. **Raw scholarly resources** — books, articles, reports, maps, datasets, statistics, and historical sources.
3. **Wikidot student-facing notes and links** — explanations, readings, uploaded material, maps, data links, and other learning support.

These layers are compared topic by topic before a revised note or slide is treated as mature.

```text
Historical PPT
+ Raw repository
+ Website learning layer
→ Triangulation
→ Revised note
→ Slide plan
→ Classroom deck
→ Student learning package
```

## What each main area does

| Area | Owner purpose |
|---|---|
| Supervisor Home | Shows the semester and the three-layer production model. |
| Lecture Pair Workspace | Shows the fixed Tuesday Part A and Friday Part B teaching arc. |
| Resources | Selects candidate evidence for active course production. |
| Historical Decks | Inspects inherited teaching without changing the original files. |
| Revised Notes | Builds working explanations with visible provenance. |
| Slide Plan | Connects teaching purpose, evidence, speaker cue, and citation. |
| Lecture Triangulation | Compares the historical PPT, raw resources, and website layer by topic. |
| Deliverables | Produces local versioned drafts after evidence gates pass. |
| Governance and Git Readiness | Shows read-only preservation and publication boundaries. |

## Important boundaries

The historical census lists discovered material. It is not the canonical resource registry. A resource enters the registry only after triangulation review and an explicit instructor admission decision.

Likewise, a student learning package is not automatically verified, approved, public, or ready for students.
